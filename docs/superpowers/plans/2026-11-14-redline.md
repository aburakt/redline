# redline Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Zero-dependency hooks that brief AI coding agents on machine state at session start and advise/deny heavy or blocking shell commands when the machine can't take them — across Claude Code, Codex, Cursor, Gemini CLI, Copilot CLI on macOS, Linux, Windows.

**Architecture:** One POSIX `sh` script (`bin/redline`) and one PowerShell script (`bin/redline.ps1`) with identical subcommands and output, driven by shared data files (`rules/*.tsv`). Metrics are cached in a temp file (stale-while-refresh). A per-agent adapter layer inside each script maps a verdict (`ok` / `advise` / `deny`) to that agent's hook JSON. One shared test suite runs every case against every implementation available on the runner.

**Tech Stack:** POSIX sh, PowerShell 5.1+/7; tests with `bun test` (dev-only, never needed by users); GitHub Actions matrix (macos, ubuntu, windows).

**Spec:** `docs/superpowers/specs/2026-11-14-redline-design.md`

## Global Constraints

- Users need nothing installed: no Node/Python/Bun/Go/jq at runtime. (Installer *may* use jq/python3/node if present for JSON merge; without them it prints the snippet and touches nothing.)
- p95 hook latency with warm cache: ≤ 100 ms macOS/Linux, ≤ 300 ms Windows.
- Silence when fine: pre-command hooks emit nothing (or the agent's minimal "allow") when verdict is `ok`.
- Never kill or stop processes. Deny only when memory or disk is **critical**. `REDLINE=off` disables everything (verdict always `ok`, briefing empty).
- Thresholds: mem **warn** avail < 25 % or OS pressure warn; **critical** avail < 10 % or OS pressure critical. Disk **warn** < 10 GB, **critical** < 3 GB. CPU **warn** load/cores ≥ 2 (advise only, never deny). Swap is reported, never a trigger.
- Linux pressure from PSI `/proc/pressure/memory`: warn `some avg10 ≥ 20`, critical `full avg10 ≥ 20`; missing file → avail % only. macOS `kern.memorystatus_vm_pressure_level` 1/2/4 → normal/warn/critical; avail % = `kern.memorystatus_level`. Windows avail % from `Win32_OperatingSystem`.
- Session briefing ≤ ~40 tokens, one line, prefix `redline: `.
- User-level agent config only; never project-level. Installer always backs up (`<file>.redline-bak-<unix-ts>`), supports `--dry-run` and `--uninstall`; uninstall removes only entries whose command contains `redline`.
- MIT license. No telemetry, no network calls in hooks.
- Commit messages: conventional commits, one line ≤ 72 chars, no Co-Authored-By.

## Review Focus

1. **Command text appearing in paths/fields** — a `cwd` like `/work/gradle-app` or a transcript path must not trigger the gradle rule. Expect: rules match only the extracted command. Test in Task 3 (`hook ignores rule words outside command`).
2. **Concurrent hooks / cache races** — two agents firing at once must never read a half-written cache. Expect atomic write (tmp + `mv`). Test in Task 1 (`cache write is atomic`).
3. **Missing metric sources** — no `lsof`/`ss`, no PSI, no `simctl`, container without `/proc/pressure`. Expect: field omitted, verdict still computed, exit 0. Test in Task 1 (`probe survives missing tools`).
4. **Hook failure must fail open** — any internal error → exit 0 with no output (Copilot treats non-zero as deny!). Test in Task 3 (`internal error fails open`).
5. **Quotes/backslashes/newlines in advice or command** — JSON output must stay valid. Test in Task 3 (`output json is valid with hostile command`).

## Interfaces (shared by all tasks)

CLI (both scripts, identical output byte-for-byte except line endings):
- `redline probe` → refresh cache, no output.
- `redline status` → briefing line. `redline status --json` → one JSON object:
  `{"mem":{"avail_pct":71,"level":"ok"},"swap_gb":4.3,"disk":{"free_gb":18,"level":"ok"},"cpu":{"load_per_core":0.6,"level":"ok"},"heavy":[{"group":"ios-sim","mb":8700,"free":"xcrun simctl shutdown all"}],"ports":[3000,8081]}` (heavy sorted by mb desc, only groups ≥ 300 MB).
- `redline check -- <command...>` → first line `ok`, `advise`, or `deny`; second line (advise/deny) the message.
- `redline hook <agent> <event>` → reads agent payload on stdin, writes agent JSON on stdout, always exit 0. `agent ∈ claude|codex|cursor|gemini|copilot`, `event ∈ start|pre|post`.

Fake env (tests; when any is set, real probing for that field is skipped): `REDLINE_FAKE_MEM_AVAIL_PCT`, `REDLINE_FAKE_PRESSURE` (`normal|warn|critical`), `REDLINE_FAKE_SWAP_GB`, `REDLINE_FAKE_DISK_FREE_GB`, `REDLINE_FAKE_LOAD_PER_CORE`, `REDLINE_FAKE_PROCS` (`group:mb,group:mb`), `REDLINE_FAKE_PORTS` (`3000,8081`). `REDLINE_CACHE_DIR` overrides cache dir (default `${TMPDIR:-/tmp}/redline-<uid>`, Windows `$env:TEMP\redline`). Cache TTL 10 s; stale → return stale and refresh in background; absent → probe synchronously. Threshold overrides (documented config): `REDLINE_MEM_WARN_PCT` (25), `REDLINE_MEM_CRIT_PCT` (10), `REDLINE_DISK_WARN_GB` (10), `REDLINE_DISK_CRIT_GB` (3), `REDLINE_CPU_WARN` (2). Task 1 implements and tests them (`threshold override`: `REDLINE_MEM_WARN_PCT=80` + avail 71 → warn).

Verdict algorithm (`check`), evaluated over all rows of `rules.tsv` whose ERE matches the command; strongest wins (`deny` > `advise` > `ok`); advise messages are joined with ` | `:
- `REDLINE=off` → `ok`.
- `when=always` → advise.
- `when=running:<group>` → advise if that group is in `heavy`.
- `when=ports` → advise if `ports` non-empty (message names the ports).
- `when=pressure` → deny if mem or disk critical; advise if mem/disk/cpu warn; else ok.
- `when=disk` → deny if disk critical; advise if disk warn.
Message format: `redline: <state summary>. <rule advice>` where state summary is e.g. `memory warn, 18% free; top: ios-sim 8.7G (free: xcrun simctl shutdown all)`.

Adapter mapping (from official docs, fetched 2026-11-14):

| agent | start | pre ok | pre advise | pre deny | post |
|---|---|---|---|---|---|
| claude, codex | `{"hookSpecificOutput":{"hookEventName":"SessionStart","additionalContext":L}}` | no output | `{"hookSpecificOutput":{"hookEventName":"PreToolUse","additionalContext":M}}` | `{"hookSpecificOutput":{"hookEventName":"PreToolUse","permissionDecision":"deny","permissionDecisionReason":M}}` | — |
| cursor | `{"additional_context":L}` | `{"permission":"allow"}` | `{"permission":"allow","agent_message":M}` | `{"permission":"deny","user_message":M,"agent_message":M}` | — |
| gemini | `{"hookSpecificOutput":{"hookEventName":"SessionStart","additionalContext":L}}` | no output | no output; write M to `<cache>/pending-gemini` | `{"decision":"deny","reason":M}` | if pending: `{"hookSpecificOutput":{"hookEventName":"AfterTool","additionalContext":M}}`, delete file |
| copilot | `{"additionalContext":L}` | no output | no output (briefing only) | `{"permissionDecision":"deny","permissionDecisionReason":M}` | — |

Command extraction from stdin: value of the first `"command"` key (also tolerate escaped `\"command\":\"...\"` inside a string-encoded `toolArgs`), JSON-unescaped. If none found → verdict `ok` (never match raw payload).
